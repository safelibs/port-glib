# Debian Patch Provenance

The final safe package keeps `debian/source/format` at `3.0 (quilt)` and keeps `safe/debian/patches/series` empty intentionally. The Ubuntu/Debian quilt queue targets upstream C files; the final workspace builds Rust crates, translated Rust modules, and safe-owned package staging instead.

Each original patch is therefore classified as either absorbed into the safe source/package/test policy or obsolete with an explicit rationale. Package payloads now resolve from `build-final`, `safe/debian/`, or `safe/vendor/original/` script templates where those templates are the shipped interface; no installed helper or static archive is sourced from `safe/vendor/build-check`.
